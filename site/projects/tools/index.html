Tools

Decoders, diffs and JSON helpers

Launch GitHub

Why I built it

Working at Pendo, or really on any web application, I kept either googling the same simple tools, buried in ads and popups, or writing one-off scripts to debug something. So I bundled them into one place: a one-stop shop for exactly the workflows I find myself repeating.

What it does

A handful of small browser tools for working with JSON:

  • jzb decodes and encodes JZB, which is URL-safe base64 of zlib-compressed JSON. Either side can be edited.
  • b64 decodes and encodes base64 text, formatting it when it's JSON.
  • minifier beautifies or minifies JSON in either direction.
  • diffhist takes a JSON array of snapshots and steps through the diff between each consecutive pair. It can filter to changes that touch a field, reverse the order, hide unchanged values, and turn epoch timestamps into readable dates.
  • mapper applies a JavaScript mapping function like x => x.user to JSON, then filters the result down to dotted paths like user.name, tags.k.

How it's built

Code
Plain HTML and JavaScript with no build step, one page per tool. jzb uses pako for zlib, and everything runs in the browser, so nothing pasted in is ever sent anywhere.
Hosting
GitHub Pages, at mattlove.dev/tools.
Deploying
GitHub Pages publishes straight from the main branch on every push.
