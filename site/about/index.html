About

NC State

I studied Computer Science at NC State, graduating in 2014. My favorite classes were Operating Systems, Networks, and File Organization & Processing: the courses about what's actually happening underneath the code. I also did undergraduate research for my Networks professor.

Dell EMC · 2014–2021

Those interests lined up well with Dell EMC, where I spent seven years building enterprise storage OS software in C89, on a mature, high-reliability codebase with tens of millions of lines of code.

The biggest project was NFSv4, which I helped take from greenfield to production as a core team member. I also scaled concurrent clients 4x, from 2,000 to 8,000 connections, by replacing a global-mutex linked list in the export authentication hot path with a per-entry-mutex hash table. I was also the branch keeper for the multi-year feature branch, keeping merges clean across the entire codebase.

I also developed a cross-platform SDK that shipped on Linux, AIX, HP-UX, Solaris, and Windows, which meant a lot of time in platform-specific code paths, per-OS build systems, and preprocessor macros. And I implemented a hot-swappable update system that patched tens of thousands of backup clients without reinstalling them: a small wrapper binary checks versions with the server and dynamically loads the implementation binary. Our principal architect filed a patent on the design, since granted as US 10,853,094.

Along the way I built developer tools that spread across the team on their own, like a multiplexed SSH session manager with a persistent daemon that could broadcast a command to many machines at once.

Pendo · 2021–2026

In 2021 I joined Pendo, moving from C to Go on Google Cloud. I started on the Enterprise & Product-Led Growth team as the primary backend engineer for a full SCIM implementation with Okta, which let enterprise customers automate user provisioning. I also delivered a free trial product end to end, from tier enforcement on routes to gracefully deactivating features when a trial expired.

In 2022 I moved to Analytics, where I led backend development of a comprehensive reporting tool. I also added referential integrity across the platform, so shared resources like segments and metadata fields couldn't be deleted while reports, messaging rules, or other features still depended on them.

In 2023 I joined Guides, and within a year I was the sole backend engineer for two frontend teams and the go-to expert on guides backend systems. That included the guide delivery service, the platform's most trafficked endpoint, which evaluates each visitor's behavior against targeting rules in real time, in parallel across candidate guides, behind a three-tier cache. I fixed a multi-year bug that made translated guides return 403 errors by tracking down four separate failure modes, then audited the whole platform and repaired roughly 80,000 missing files across 10,000 guides without reprocessing any of them.

Guides was also where I got to build new things: A/B guide experiments with deterministic hash-based visitor assignment, a production RAG system that brings customers' knowledge bases into guide generation, and Guide AI Localization, a hackathon project that became a near-universally adopted feature.

In 2025 I moved to Platform Engineering and took ownership of the event ingestion pipeline and the jobs framework that every team's async work runs on. I automated a 5–6 hour manual data migration into a configuration-driven Airflow pipeline, using Claude Code from the technical spike through implementation while I focused on architecture, validation, and testing. I replaced another manual process, five endpoint calls plus a lot of log watching, with a durable state machine that shows its progress in the UI. And I profiled a Go event categorization algorithm with pprof against production data, which fixed a chronic SLA breach for a high-volume customer and improved throughput for everyone.

I was also a Tier 1 on-call engineer, and served as incident commander for a company-wide SEV0, leading a multi-day recovery across three engineering teams and building tooling to reconstruct each customer's state precisely.

The tools habit came with me from Dell EMC. At Pendo I built Postboy, a REST automation platform adopted across engineering: a Go scripting engine on top of GoLand's HTTP client, a Chrome extension that syncs session tokens into local env files, and a composable library for running request pipelines in parallel. A companion tool that statically analyzes the monorepo to generate a request file for every backend route won the CDO Innovation Award.
